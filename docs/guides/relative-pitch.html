You become more confident at finding notes, following melodies and hearing how sounds relate to one another.

02 / Match a keyboard key

One note.
Two ways to match it.

Find the Note asks for a name. Find the Pitch asks for the exact high or low version too.

Find the Note

Press Play. Tap the keyboard keys to compare their sounds with the note you heard. Select the matching key, then press Submit Answer.

Find the Pitch

A note name can appear in several places on a keyboard. Here, find the place that matches how high or low the sound is.

G3A lower G
G4The matching G
G5A higher G

The number identifies the note’s keyboard range, called an octave. If you hear G4, choose G4. G3 has the same letter name but sounds lower.

Move between the keyboard ranges to find the sound. On a phone, swipe to browse them. The available keys depend on your chosen instrument.

Listen again when you need to.

Use Replay to start again, or move the audio slider to hear a particular part. Check your selected key before submitting.

03 / Learn the seven names

Do, Re, Mi…
Which one did you hear?

Relative Tone Pitch #1 and #2 use the same seven answer names.

Hear one note. Choose one name.

Press Play, listen to the note and choose the name that matches it. You can change your choice before pressing Submit Answer.

DoReMiFaSoLaTi
Example answer: Mi

Choose Mi when that is the note name you recognise in the question.

#1 · A smaller range

The sounds stay in one small range, helping you become familiar with the seven names.

ReMiFa

The quiz plays one note at a time, not this whole row.

#2 · Higher and lower

The same seven names appear over a wider range of high and low sounds.

Mi→Mi

A lower Mi and a higher Mi still have the same answer name.

Use Listen Mode when it is available

Listen Mode contains reference examples to help you get familiar with the sounds. The question’s Play button plays the sound you are answering.

Follow the names on the answer buttons.

In these two quizzes you choose Do, Re, Mi, Fa, So, La or Ti. You are not choosing letter names such as C or D.

What does Second, Third or Fourth mean?

Count the note names from the starting note to the ending note. Include both ends. A third from Do is Do, Re, Mi.

05 / Find where the music settles

Find the song’s
home note.

The home note, also called the tonal centre, is the note the music feels settled on.

Find the Key #1

Play the music. Try humming the note that would make a natural ending.

Tap the keyboard keys to compare sounds. Choose the home note you hear, then submit.

Example: home note C → choose C

Find the Key #2

A highlighted keyboard key gives you a known reference note.

Hear that note and the music. Work out how the reference fits the song, then trace back to its home note.

Choose the home note, rather than automatically choosing the reference.

A worked example for #2

The highlighted reference is A♭. You recognise its relationship to the home note as a flat sixth (♭6).

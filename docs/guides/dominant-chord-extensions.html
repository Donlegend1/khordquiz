Dominant Chord Extensions · Level 1

Dominant 7 is already given. Listen and select all the extra extensions you hear above that chord.

Listen to the whole chord

Press Play and listen to how the extra notes change the dominant seventh chord. You can listen again whenever you need to.

Select all the added extensions

Choose all the extensions present, such as ♭9 and ♯11, or 9 and 13. More than one answer is needed. Tap a selected extension again to remove it.

Check and submit

Check every selected extension, then press Submit Answer. The seventh is already part of the given Dominant 7 chord, so there is no separate 7 button to choose.

What changes in this quiz?

A dominant seventh chord already contains four notes. In F, they are F, A, C and E♭. This quiz asks which extra notes are added to that chord. The ♭ sign means a lowered note and ♯ means a raised note, by one keyboard step, counting white and black keys. Group 1 contains seven chords with a lowered ninth (♭9), a raised ninth (♯9), or both. This lesson uses chords built on F. The chords use their basic arrangement, with no doubled or shifted notes. Select every extension present. For example, a chord with both ♭9 and ♯9 needs both buttons selected.

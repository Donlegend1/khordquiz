What changes in this quiz?

A scale is a set of notes played in order. Each example rises to a higher version of its starting note, then returns to that starting note. This lesson uses all twelve starting notes. Ionian and Lydian differ at the fourth note. Over C, Ionian uses F and Lydian uses F♯. Listen for that change in the middle of the scale. Choose the scale name. You do not need to enter the notes one by one.

What changes in this quiz?

A scale is a set of notes played in order. Each example rises to a higher version of its starting note, then returns to that starting note. This lesson uses all twelve starting notes.
